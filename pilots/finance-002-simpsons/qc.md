# QC checklist — every still, before it goes into a video

Review at FULL size (never thumbnails) with a zoomed crop of every face.

| Check | Pass when |
|---|---|
| Eyes | both eyes in the same state; matches the shot's expression; closed = two curved lines |
| Character | same face, hair, light blue crew-neck tee, jeans; matches the expression sheet |
| People count | exactly the people the shot asks for (no clones, no tiny duplicates) |
| Hands | four fingers, nothing fused or extra |
| Text | no letters, numbers or gibberish anywhere |
| Background | pure white (faint line-art props only) |
| Glow | green = good thing, red = bad thing, as the shot says |

- Face-focused shots: generate **2 versions**, keep the better one.
- A failed still is **fixed with an eye/face-only edit** (Qwen edit, "change nothing else"), not re-rolled,
  unless the whole composition is wrong.
- Log each rejection in the video's qc notes (shot, what failed, how it was fixed).
